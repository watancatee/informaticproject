🏛️ Архитектура SmartBudget

Архитектурная схема взаимодействия клиентского интерфейса, облачной базы данных и нейросетевых сервисов.

СХЕМА АРХИТЕКТУРЫ СИСТЕМЫ:
[ 📱 Пользователь (Авторизация / PIN) ]
        │
        ▼
[ 💻 Интерфейс (SPA: smartbudget.html) ]
        │                        │
        ▼ (CRUD & Auth)          ▼ (REST / Prompts)
[ ☁️ Supabase Cloud ]     [ 🤖 Gemini 2.5 Flash API ]
(PostgreSQL + RLS)        (ИИ-Консультант)
1. Авторизация и разграничение:
Вход по Email/паролю или PIN-коду. Каждый пользователь видит только свои записи благодаря разделению по user_id и политикам RLS в базе данных.
2. База данных (CRUD):
При добавлении расхода вызывается метод создания (Create), при открытии страницы — чтение (Read), при удалении — (Delete). Синхронизация с таблицей expenses.
3. ИИ-интеграция:
Прямой вызов Gemini 2.5 Flash API с контекстом бюджета и диеты пользователя для генерации персональных рекомендаций.
